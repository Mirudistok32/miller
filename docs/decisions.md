# Принятые решения

| Решение | Причина |
| --- | --- |
| **Каркас копией из pigeon-post** (30.10.2026) | Просьба пользователя: тот же стек и инструменты, но без общего кода — проекты живут и публикуются отдельно. |
| **Родник всегда сверху, мельница снизу** | Одна понятная композиция «вода течёт вниз»; на телефоне вертикальная сцена ложится в экран, поле не поворачивается (у всех одинаковый уровень дня). |
| **Победа — вода дошла до колеса, проливы разрешены** | Так правило из ТЗ: «провести воду от истока до колеса». Без проливов — отдельная ачивка «Ни капли мимо». |
| **Поворот в обе стороны, каждый — один ход** (30.10.2026, вместо «только по часовой») | Решение пользователя: без обратного поворота ошибка стоит трёх лишних нажатий. Левая кнопка, тап и Enter — по часовой; правая кнопка, долгое нажатие (400 мс) и Shift+Enter — против. Палец решает по таймеру и при отпускании, поэтому тап срабатывает на отпускании, а не на касании. Решатель считает цену клетки по короткой стороне, автопилот крутит так же. |
| **Сид v2: кратчайший путь один, всего путей до 4** (30.10.2026) | Новая версия сида: решатель считает повороты в обе стороны, и все уровни изменились. Лишние обходы снимает замена обманки (форма, затем развилка на пути, пустая клетка — крайний случай), а не только перебор сидов: на v1 порог держали лишь 26 % поздних уровней. Строгой единственности нет: обманки должны оставаться правдоподобными. Порог действует на всех ступенях и уровне дня; старые недоигранные уровни отсекает ключ `…:v1:…`, старые решения дня показываются по новому полю. |
| **Отмена возвращает поле, но не ход** (30.10.2026) | Решение пользователя: честная цена помощи. Счётчик и часы не откатываются, поэтому «perfect» с отменой недостижим, зато ошибка не заставляет начинать заново. История живёт в партии и не сохраняется: после перезагрузки отменять нечего. |
| **Подсказка честно стоит** (30.10.2026) | Решение пользователя: жёлоб она не крутит, но лишает третьей капли, «perfect» и рекорда по лишним ходам и видна в результате как 💡. Считается заново от текущего поля. Одна подсказка на поле не считается дважды, пока игрок не сделал ход. Рестарт и перезагрузка счётчик не сбрасывают: иначе цену можно было бы обойти. `Best.extra` стало необязательным: первое решение с подсказкой рекорда по ходам не даёт. |
| **Два хостинга, один основной адрес** (30.10.2026) | Просьба пользователя: GitHub Pages и Vercel. Сборка одна и та же, файл самодостаточный, поэтому настройки минимальны. Основной адрес один (Pages): canonical и текст результата ведут на него и с копии на Vercel, чтобы поисковик не видел двух разных сайтов. Заголовки кэша на Vercel: `index.html` и превью проверяются каждый раз, иначе игрок получил бы старую игру, а она меняется вместе с версией сида. |
| **Часы идут с первого хода** | Как в сапёре: время на чтение подсказки и разглядывание поля не штрафуется; пауза и уход со вкладки часы останавливают. |
| **Уровень дня — первое решение даты** | Решение видно на поле, повтор был бы нечестным; «заново» в тот же день считается попыткой и попадает в текст результата. |
| **Текст результата без поля** | Рисунок пути выдал бы решение тем, кто ещё не играл; вместо него — капли за точность (три — минимум ходов). |
| **Бесконечный режим — уровни по номеру, а не случайная серия** | Уровень N у всех одинаков, прогресс не теряется; рекорд — по размеру поля (лучшее время и меньше всего лишних ходов), потому что сравнивать время разных полей бессмысленно. |
| **Окно минимума ходов, меньше развилок на высоких уровнях** | Замер на 300 сидах: чем больше развилок и обманок, тем больше обходных путей и тем меньше нужно ходов (медиана 15 при 30 % развилок против 23 при 10 %). Сложность растёт размером поля, длиной пути и числом ходов. С сида v2 окна подобраны заново, добавлена ступень 40+ (таблица — PLAN-LOG, пункт 1.2). |
| **Решатель отдельно от генератора** | Генератор знает задуманный путь, но минимум ходов и проверку решаемости считает независимый перебор — так тесты ловят ошибки генератора. |
| **На низком экране пруд и мельница уходят за край** | На телефоне боком клетка иначе меньше 40 px. Клетки важнее декора: лоток родника и верх колеса остаются видны. |
| **`?seed` и `?autoplay` не пишут итог** | Режимы для e2e, скриншотов и превью; ачивки за них были бы нечестными. |
| **Недоигранный уровень сохраняется на каждом ходу** | Перезагрузка, закрытая вкладка или севший телефон не теряют партию; повреждённый прогресс просто забывается — он не ценность. |
