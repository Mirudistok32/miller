# Архитектура

```text
main.ts → presentation → application → domain ← infrastructure
```

| Папка | Что внутри |
| --- | --- |
| `domain/grid.ts` | Стороны-биты, формы жёлобов (прямой, угол, развилка), поворот, поле |
| `domain/flow.ts` | Вода: обход от родника, мокрые клетки, проливы, решено ли; время прихода воды в клетку |
| `domain/solver.ts` | Минимум ходов: перебор простых путей с отсечением по оценке снизу; счёт всех путей для баланса |
| `domain/generator.ts` | Уровень из сида: путь воды, обманки, перемешивание, проверка решателем |
| `domain/levels.ts` | Уровень дня, ступени бесконечного режима, демо; сиды с версией |
| `domain/calendar.ts` | Даты ГГГГ-ММ-ДД без `Date`: номер дня, сдвиг, серия |
| `domain/play.ts` | Партия: поворот-ход, часы с первого хода, «заново» |
| `domain/result.ts`, `achievements.ts`, `save.ts` | Итог, капли, ачивки, сохранение, копия, объединение |
| `application/game.ts` | Экраны, режимы, демо в меню, автопилот, запись итога и недоигранного уровня |
| `application/saveStore.ts`, `backup.ts` | Единственная точка записи; экспорт и импорт копии |
| `application/ports/` | `SaveRepository`, `Sound`, `Clock` |
| `infrastructure/` | `localStorage` с откладыванием повреждённых данных, Web Audio, системные часы |
| `presentation/layout.ts` | Масштаб и место поля под панелями; клетка по точке |
| `presentation/render.ts` | Кадр: деревня, поле, вода, родник, мельница, погода |
| `presentation/ui.ts` | Экраны из `index.html`, HUD, ввод, фокус, объявления, буфер обмена |

## Уровень

1. Сид → родник над случайным столбцом, колесо — под другим.
2. Путь воды: путь по случайному остовному дереву (алгоритм Уилсона), удлинённый
   «выпячиваниями» до длины из `pathShare`.
3. От пути растёт новое дерево — его ветви становятся обманками; часть клеток пустует
   (камень, кочка, пень), часть клеток пути — развилки.
4. Лишние обходы снимаются заменой обманок: у клетки с наибольшим числом обходов меняется форма,
   пока путей не станет не больше `maxPaths`; не вышло — новая раскладка.
5. Перемешивание: клетки пути чаще встают неправильно. Если вода всё равно доходит до колеса,
   клетки доворачиваются, в крайнем случае закрывается родник.
6. Решатель считает минимум ходов по полю (короткой стороной поворота), не зная задуманного
   пути; перемешивание повторяется, пока кратчайший путь не станет один, а минимум не попадёт в
   окно `minMoves…maxMoves` ступени.

Решатель: в решённом поле всегда есть простой путь от родника до колеса, клетки вне пути
трогать не нужно. Цена клетки — сколько поворотов, чтобы открылись две нужные стороны.
Перебор простых путей в порядке оценки, отсечение — по нижней оценке (тот же путь без запрета
проходить клетку дважды, считается заранее). Бюджет узлов — страховка; уровни, где минимум
не доказан, генератор не выдаёт.

## Поток кадра

1. `requestAnimationFrame` → `game.tick(ms)`; шаг кадра не больше 0,1 с.
2. Часы партии идут, только пока открыт экран игры, сделан первый ход и уровень не решён.
3. Поворот → новая вода (`wetTimes`): мокрые клетки остаются как были, новые заполняются
   клетка за клеткой через `FLOW_CELL` после соседа, из которого вода пришла.
4. Решение → время колеса (вода дошла до нижней клетки) и итога (+`WHEEL_SHOW`), итог
   записывается сразу.
5. `view.frame` рисует сцену: неподвижное — из запасного холста (перерисовка при смене
   размера, уровня или сезона), живое — каждый кадр; HUD — только при изменении значений.

## Сборка

`vite build` с `base: './'`, одним JS и одним CSS, шрифты — `data:`. `scripts/postbuild.mjs`
вкладывает их в `dist/index.html` и падает, если что-то не встроилось. Рядом лежат только
файлы из `public/` (`og.png`).

## Тесты

- `generator.test.ts` — 1200 уровней дня и 1200 уровней бесконечного режима: решаемы,
  не решены на старте, минимум доказан, решение решателя собирает путь; крайние настройки
  не вешают генератор; детерминизм, разнообразие, рост сложности.
- `solver.test.ts` — решатель и счётчик путей совпадают с полным перебором на случайных полях
  (счётчик ещё на полях из развилок и настоящих уровнях), бюджет.
- `flow.test.ts`, `grid.test.ts`, `play.test.ts` — вода, проливы, повороты, часы, «заново».
- `daily.test.ts` — календарь без `Date` (каждый день 1900–2200), уровень даты одинаков,
  снимок уровня 30.10.2026.
- `save.test.ts`, `localSaveRepository.test.ts` — формат, ачивки и серии, рекорды, копия;
  пусто, мусор, недоступное и переполненное хранилище.
- `game.test.ts` — экраны, режимы, запись итога, продолжение после перезагрузки, автопилот.
- `layout.test.ts` — поле в свободной части окна на 8 экранах, клетка ≥ 40 px на телефоне.
- `architecture.test.ts`, `contrast.test.ts` — границы слоёв и WCAG AA токенов.
- e2e — открытие с диска без внешних запросов, мышь, тап, клавиатура, решение тестового
  уровня, рестарт, сохранение после перезагрузки, буфер обмена, бесконечный режим,
  повреждённое и недоступное хранилище, копия, автопилот; ноль ошибок в консоли.
