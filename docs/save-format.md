# Формат сохранения

Ключ `miller:save` (`localStorage`), JSON:

```json
{
  "schemaVersion": 1,
  "sound": true,
  "theme": "system",
  "daily": {
    "2026-10-30": { "moves": 21, "min": 17, "time": 83.6, "attempts": 1, "rots": "0123…" }
  },
  "endless": { "level": 7 },
  "best": { "daily": { "time": 83.6, "extra": 4 }, "6x6": { "time": 51.2, "extra": 3 } },
  "progress": {
    "endless": { "key": "endless:v3:7", "rots": "2013…", "moves": 5, "time": 12.4, "started": true, "attempts": 1 }
  },
  "achievements": { "first-mill": "2026-10-30T12:00:00.000Z" },
  "stats": { "solved": 6, "perfect": 1, "dry": 0, "seasons": ["spring", "autumn"], "bestStreak": 2 }
}
```

- `theme`: `system | light | dark`.
- `daily[дата]` — первое решение уровня этой даты: ходы, минимум, время (с), попытки и
  повороты решённого поля (`rots`, цифры 0–3 по клеткам). Необязательное `hints` — сколько
  взято подсказок (нет поля — ни одной). Хранятся последние 400 дней.
- `endless.level` — уровень бесконечного режима, который играется сейчас (с 1).
- `best[ключ]` — рекорды: `daily` для уровня дня, `<столбцы>x<ряды>` для полей бесконечного
  режима. `time` — лучшее время, `extra` — меньше всего ходов сверх минимума (могут быть из
  разных решений). Решение с подсказкой `extra` не обновляет, поэтому поля может не быть.
- `progress[режим]` — недоигранный уровень. `key` — чей он (`daily:v3:<дата>`,
  `endless:v3:<номер>`): не совпал с текущим уровнем — прогресс не применяется, поэтому ключи
  прежних версий после смены версии сида просто забываются. Необязательное `hints` — взятые подсказки. Повреждённый
  прогресс при чтении просто забывается, остальное сохранение не страдает.
- `achievements` — id → дата открытия. id: `first-mill`, `daily`, `streak-3`, `streak-7`,
  `perfect`, `perfect-5`, `swift`, `dry`, `level-10`, `level-25`, `four-seasons`. Незнакомые
  id при чтении пропускаются (копия из версии новее не ломает старую).
- Не прочиталось — данные откладываются в `miller:save-corrupt`, игра начинает с чистого
  листа и сообщает об этом в меню. `localStorage` недоступен — игра работает в памяти и
  предупреждает.

## Резервная копия

`miller-backup-ГГГГ-ММ-ДД.json`:

```json
{ "format": "miller-backup", "schemaVersion": 1, "exportedAt": "…", "appVersion": "0.1.0", "data": { … } }
```

Импорт проверяет формат, версию (новее — отказ), размер (до 300 КБ) и поля, затем
**объединяет**: уровни дня — все даты (при совпадении — решение с меньшим числом подсказок,
затем ходов и времени), рекорды — лучшие, ачивки — все с самой ранней датой, бесконечный режим и итоги — большие,
настройки и недоигранные уровни — текущие.

## Миграции

Пока одна версия. Новая версия схемы — чистая функция в `domain/save.ts`, тест на примере
старого файла, старый ключ живёт до отдельного пункта плана.
