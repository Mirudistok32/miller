# Мельник

Пиксельная головоломка на canvas для портфолио: повернуть деревянные жёлоба так, чтобы вода
из родника добежала до мельничного колеса. Интерфейс, документация и ответы — по-русски.

Общие принципы и имена команд — `../agent-base/docs/` (principles, conventions). Здесь —
только то, что отличает этот проект. Каркас скопирован из `../pigeon-post` (общего кода нет:
файлы живут в каждом проекте свои).

## Стек и запуск

- Vite + TypeScript без фреймворка, рисование — `canvas` 2D, звук — Web Audio; данные
  пользователя — `localStorage` (`miller:*`), бэкенда нет.
- Открыть: `npm run build`, затем двойной клик по `dist/index.html` (всё вложено в один файл,
  `scripts/postbuild.mjs`). Разработка — `npm run dev`. Публикация: GitHub Pages на пуш в
  `master` или `main` (`.github/workflows/pages.yml`) и Vercel (`vercel.json`), инструкция в
  `README.md`; репозиторий — <https://github.com/Mirudistok32/miller>.
- `?seed=42&level=6&season=winter` — тестовый уровень из сида (сложность как у уровня 6
  бесконечного режима), итог не записывается. `?autoplay` — уровни решает автопилот, итог не
  записывается: для e2e, скриншотов и превью.

## Правила

- Слои (`docs/architecture.md`): `domain/` — чистые функции, время и ввод приходят
  аргументами, никакого `Math.random`/`Date`/DOM; границы проверяет `tests/unit/architecture.test.ts`.
- Уровни — из сидов `miller:daily:v3:<дата>` и `miller:endless:v3:<номер>`. Изменение
  генератора меняет все уровни (уровень дня у игроков разойдётся, рекорды обесценятся):
  новая версия сида — осознанное решение в `docs/decisions.md`. Снимок уровня 30.10.2026 в
  `tests/unit/__snapshots__/` ловит такие изменения.
- Любое изменение генератора или решателя — прогнать `tests/unit/generator.test.ts` и
  `solver.test.ts`: каждый уровень решаем, ни один не решён на старте, минимум ходов доказан,
  решатель совпадает с полным перебором.
- Тексты экранов — в `index.html` (видны без JS), подписи на лету — `src/content/texts.ts`.
- id ачивок и поля сохранения — ключи в `localStorage`: не переименовывать без миграции
  (`docs/save-format.md`).

## Проверки

- `npm run check` — типы, линтер, формат, юнит-тесты (генератор на 2400 сидах, решатель
  против перебора, раскладка, контраст токенов, границы слоёв). `npm run check:full` — +
  сборка и e2e по `file://` (ноутбук и телефон 390 px: мышь, тап, клавиатура, решение,
  рестарт, сохранение, буфер обмена).
- Визуально: `npm run shots [фильтр]` после `build` — экраны × 1280/390/844×390 ×
  тёмная/светлая, времена года, первый уровень, повреждённое сохранение; ошибки консоли и
  прокрутка вбок.
- Превью ссылки: `npm run og` → `public/og.png`.
- Баланс: `npm run balance [выборка]` — минимум ходов и пути по ступеням и уровню дня, таблица
  для журнала.

## Нельзя

- Менять и удалять ключи `localStorage` и id ачивок без миграции.
- Глушить правила линтера, удалять тесты, снижать пороги ради зелёного гейта.
- Подгонять тест генератора под сломанный уровень или обновлять снимок уровня дня без новой
  версии сида: чинить генератор.
- Трогать `../pigeon-post` из этого проекта.
