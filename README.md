# Мельник

Пиксельная головоломка в браузере: над полем бьёт родник, внизу стоит мельница. Поворачивайте
деревянные жёлоба — прямые, углы и развилки, — пока вода не добежит до колеса. Тогда вода
бежит по собранному пути, колесо начинает крутиться, из двери летит мука.

**Уровень дня** — один на всех и меняется в полночь: результат (ходы, время, капли за
точность) копируется текстом для друзей и не выдаёт решения. **Бесконечный режим** — уровень
за уровнем: поле растёт с 4×4 до 7×7, путь воды длиннее, каждые пять уровней новое время года.
Одиннадцать ачивок, рекорды по размерам полей, серия дней, резервная копия в JSON.

Всё нарисовано кодом на `canvas`: деревня с избами, ёлками и берёзами, ручей, пруд родника,
мельница с колесом, снег, лепестки, пух и листья. Звуки синтезируются Web Audio — ни одного
файла.

## Как открыть

```bash
npm install
npm run build
```

Затем откройте **`dist/index.html`** двойным кликом — сервер не нужен. Этот же файл
выкладывается на любой статический хостинг: пути относительные, поэтому игра работает и в корне
домена, и в подпапке.

## Публикация

**GitHub Pages.** Запушить в `master` или `main`, в настройках репозитория выбрать
Settings → Pages → Source: **GitHub Actions**. Дальше каждый пуш проверяет и выкладывает игру
(`.github/workflows/pages.yml`).

**Vercel.** Add New → Project → выбрать репозиторий. Настройки уже в `vercel.json`, менять ничего
не нужно: каждый пуш публикует игру, а ветки получают ссылки предпросмотра.

**Адрес сайта.** Основной адрес записан в `index.html` (canonical, `og:url`, `og:image`, JSON-LD)
и в `src/content/texts.ts` (ссылка в тексте результата). Сейчас это
`https://mirudistok32.github.io/miller/`. Другое имя репозитория или домен — поправить эти места;
`npm test` назовёт те, что разошлись. Копия на Vercel показывает на этот же адрес: поисковик и
текст результата ведут на один сайт.

`dist/index.html?autoplay` — уровни решает автопилот (в рекорды не идёт);
`?seed=42&level=6&season=winter` — тестовый уровень из сида.

## Управление

| Что сделать | Что будет |
| --- | --- |
| Нажать на жёлоб мышью или пальцем | Жёлоб повернётся на четверть оборота по часовой стрелке |
| Правая кнопка мыши или долгое нажатие пальцем | Жёлоб повернётся против часовой, это тоже один ход |
| Стрелки | Выбрать клетку с клавиатуры |
| Enter или пробел | Повернуть жёлоб под курсором; Shift+Enter — против часовой |
| Z или Ctrl+Z, кнопка ↶ | Отменить ход: поле вернётся, а ход останется потраченным |
| H, кнопка 💡 | Подсказка: подсветит жёлоб, который стоит повернуть; после неё не больше двух капель и нет «без лишних ходов» |
| Esc или P | Пауза; M — звук; кнопка ↻ — начать уровень заново |

Вода сразу бежит по всем жёлобам, что стыкуются с родником, — видно, куда она дошла. Из
открытых концов вода проливается: это не мешает, главное — довести её до колеса. Каждый
поворот — ход; после решения игра показывает минимум ходов, его считает решатель. Время идёт
с первого поворота.

## Команды

```bash
npm run dev            # разработка
npm run build          # проверка типов, сборка в один dist/index.html
npm run check          # типы, линтер, формат, юнит-тесты
npm run check:full     # check + сборка и e2e (Playwright по file://, ноутбук и 390 px)
npm run shots          # снимки всех экранов в .screenshots/
npm run og             # картинка превью public/og.png
npm run balance        # таблица баланса: минимум ходов и пути по ступеням и уровню дня
npm run format         # Prettier
```

## Стек

- **Vite** + **TypeScript** без фреймворка, `canvas` 2D, Web Audio
- **Vitest** (генератор, решатель, вода, сохранение, раскладка, контраст, границы слоёв),
  **Playwright** (e2e по `file://`)
- Шрифты Ubuntu, Roboto, Tektur — в репозитории, вложены в сборку

## Где что лежит

```
src/
  domain/          правила — чистые функции: поле и жёлоба, вода, решатель, генератор
                   уровней, календарь, партия, ачивки, сохранение и копия
  application/     игра без DOM: экраны, режимы, демо и автопилот, часы партии; порты
  infrastructure/  localStorage, Web Audio, часы
  presentation/    раскладка, отрисовка, палитры, экраны и HUD, ввод, стили
  content/         подписи на лету: ачивки, даты, текст результата
  main.ts          сборка всех слоёв
tests/unit/        Vitest     tests/e2e/   Playwright     scripts/   сборка и снимки
```

## Ограничения

- Рекорды и ачивки хранятся в `localStorage` этого браузера; у сайта и у файла с диска они
  разные. Перенос — «Ачивки и рекорды → Резервная копия»: копия объединяется с текущими данными.
- Если игра открыта в двух вкладках, побеждает последняя записанная.
- Уровень дня меняется в полночь по часам игрока: у друзей в других часовых поясах «сегодня»
  наступает в другое время, но у одной даты уровень один и тот же.
- На телефоне боком поле крупное, а пруд и мельница частично уходят за край экрана.
