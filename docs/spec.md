# ТЗ (30.10.2026)

Новая игра «Мельник» в отдельной папке `miller/`.

Образец — `pigeon-post/`: взять оттуда стек и каркас (Vite + TS + canvas, сборка в один
html-файл, ESLint, Prettier, Vitest, Playwright, скрипт скриншотов, настройка GitHub Pages,
AGENTS.md и README). Файлы копировать, не делать общий код. Сам pigeon-post не менять.

## Игра

- Пиксельная головоломка в том же стиле, что голубь: деревня, ручей, мельница, времена года.
- Поле — сетка с деревянными жёлобами (прямые, углы, развилки). Клик или тап поворачивает
  жёлоб, клавиатура — стрелки и Enter.
- Цель: провести воду от истока до мельничного колеса. Когда путь собран, вода бежит по нему
  и колесо крутится.
- Уровни генерируются процедурно из seed. Каждый уровень гарантированно решаем, ни один не
  решён на старте.
- Режимы: «Уровень дня» (seed по дате, одинаковый для всех; результат копируется текстом с
  числом ходов и временем) и «Бесконечный» с растущей сложностью.
- Счёт ходов, таймер, рекорд, ачивки, звук на Web Audio с кнопкой выкл, сохранение в
  localStorage с защитой от повреждённых данных.

## Тесты и проверка

- unit: генератор (1000+ seed: каждый уровень решаем решателем, генерация не зависает),
  поворот жёлобов, поиск пути воды, уровень дня одинаков для одной даты, счёт и ачивки,
  сохранение (пусто, мусор, недоступный localStorage);
- e2e (Playwright): управление мышью, тапом и клавиатурой, прохождение уровня через тестовый
  seed, рестарт, сохранение после перезагрузки, копирование результата, нет ошибок в консоли;
- скриншоты всех экранов на 390, 844×390 и 1280 px: просмотреть и исправить найденное.

Тесты не пропускать и не ослаблять, чинить причину. Не коммитить: репозиторий и публикацию
на Pages решает пользователь.

Готово, когда `npm run check:full` зелёный и скриншоты просмотрены.

## Где отступили и почему

См. `docs/decisions.md`: проливы разрешены, поворот в обе стороны, часы с первого хода,
рекорды бесконечного режима — по размеру поля, на низком экране пруд и мельница уходят за край.
